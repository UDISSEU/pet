# Nova

Mascote de desktop em pixel art para Linux, feita em Python e Tkinter. A Nova anima na área de trabalho, conversa com provedores de IA locais ou online configurados por você e oferece lembretes, foco e rotinas.

Consulte o [README do aplicativo](desktop_pet_pixel_art/README.md) para instalação, configuração, uso e testes. O código, assets e testes ficam em `desktop_pet_pixel_art/`.
